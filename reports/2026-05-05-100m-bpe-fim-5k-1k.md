## Interpretation
The run proves the larger architecture can train and checkpoint on Modal, but the perplexity is not good. This setup is still undertrained and sparse:

- 5,000 examples is small for a 100M BPE code model.
- Batch size 1 gives noisy optimization.
- FIM middle-only masking leaves fewer supervised validation tokens per eval.
- The learning rate may be aggressive for a 100M Transformer at batch size 1.

## Next Steps
1. Add gradient accumulation so the effective batch is at least 16-64 sequences.
2. Train on 50k-200k examples for 10k+ steps, tracking validation every 500-1,000 steps.
3. Add warmup plus cosine decay; start with `1e-4` to `3e-4` instead of `5e-4`.
4. Add syntax-validity and small-generation checks before full HumanEval.
5. Run HumanEval only after completions are parseable and validation perplexity is materially lower.
